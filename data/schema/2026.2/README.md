# SWIS schema 2026.2

Generated by `tools/build_schema_data.py` from the SolarWinds OrionSDK `gh-pages` branch.
Do not edit by hand; run `make data VERSION=2026.2`.

| File | Contents |
| --- | --- |
| `index.json` | One compact record per entity: base type, operations, counts, summary |
| `entities/<NS>.json` | Full records with properties, relationships, verbs, access control |
| `verbs.json` | Every verb, with typed and ordered parameters where the contract has them |
| `relationships.json` | Navigation edges: from, navigation property, to, kind |
| `manifest.json` | Counts, provenance, and the REST API surface |

See [../../README.md](../../README.md) for provenance and usage, and
[../../../docs/schema/using-the-data.md](../../../docs/schema/using-the-data.md) for
worked examples.

Properties are listed as each entity **declares** them. Inherited members are not
repeated, so `Uri` appears on `System.Entity` rather than on `Orion.Nodes`, even though it
is queryable on both. Resolve the full set by walking `inheritance`, or let the tooling do
it: `python3 tools/schema_query.py props Orion.Nodes` includes inherited members by
default and marks where each came from.
